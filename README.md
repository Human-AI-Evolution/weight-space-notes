# Weight-Space Notes

Numbered research notes on weight-space interventions in language
models — where post-training behavioral effects live in weight space,
how selectively they can be removed or retained, and how the
evaluation regime changes what an intervention appears to do.

Independent research. Findings are published; evaluation artifacts
and constructed weights are held — each note states explicitly what
is independently checkable.
